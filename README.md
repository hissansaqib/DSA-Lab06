## Overview
This repository contains the C++ source code for Lab 06. The lab focuses on implementing Last In First Out (LIFO) stacks and First In First Out (FIFO) queues using arrays and singly linked lists.

## Files Included
All files are written in standard C++ and can be compiled and run independently.

* **`Q1.cpp`** - Task 1: Implementation of a stack using a fixed-size array (size 5).
* **`Q2.cpp`** - Task 2: Implementation of a stack using a singly linked list, including memory cleanup.
* **`Q3.cpp`** - Task 3: A stack application that reverses a user-input word (up to 20 characters).
* **`Q4.cpp`** - Task 4: Basic insertion operations for a linear array-based queue.
* **`Q5.cpp`** - Task 5: Extension of the queue to include removal operations and empty-state index resets.
* **`Q6.cpp`** - Task 6: A menu-driven Customer Service application utilizing the linear queue logic from Tasks 4 and 5.
